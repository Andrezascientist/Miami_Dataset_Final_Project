Project overview¶

Objective¶

Predict sale prices for Miami single-family properties and compare Multiple Linear Regression with K-nearest neighbors (KNN) regression. The project investigates the relationships between property characteristics and housing prices and compares the predictive performance of Linear Regression and KNN using a separate validation dataset.

Dataset¶

The Miami Housing Dataset, originally obtained from Kaggle, contains 13,932 single-family residential property sales and 17 variables, including the target SALE_PRC.

The dataset includes property characteristics such as living area, land area, building age, structural quality, geographic location, and proximity to the ocean and central business district.

The analysis uses historical housing sales data to develop and evaluate predictive models. The variable PARCELNO identifies individual properties and is not used as a predictor.

2. Exploratory data analysis (EDA)¶

Exploratory Data Analysis (EDA) is performed to understand the distribution of housing sale prices, examine property characteristics, and identify relationships between variables before developing the regression models.

The analysis begins by examining the target variable, SALE_PRC, followed by the distributions of selected property characteristics and their correlations with housing prices. These relationships help identify potential predictors but do not establish cause-and-effect relationships.

2.1 Sale-price distribution and log transformation¶

The initial analysis revealed that housing sale prices are right-skewed, with most properties concentrated in the lower price range and a smaller number of properties having substantially higher sale prices.

To reduce this skewness, a natural logarithmic transformation is applied to the target variable:

LOG_SALE_PRC = ln(SALE_PRC)

The logarithmic transformation compresses large price values and makes proportional differences between housing prices easier to compare.

The transformation does not guarantee improved model performance or normally distributed residuals. Model performance is evaluated separately using R², RMSE, and MAE.

The following visualizations compare the original and log-transformed sale price distributions side by side, allowing us to assess how the transformation changes the distribution.

3. Prepare the modeling data¶

Target variable: The natural logarithm of sale price (SALE_PRC) is used as the target variable (y), as explained in Section 2. The transformation is applied directly to y without adding a new column to the original dataset.

Predictor variable: The original sale price (SALE_PRC) and property identifier (PARCELNO) are excluded from the predictors (X). The categorical variables month_sold and structure_quality are converted into dummy variables, with one category removed from each to avoid redundant indicators in the Linear Regression model.

Training and Validation Split: The dataset is randomly divided into 75% training data and 25% validation data using a fixed random seed for reproducibility. The training data are used to develop and optimize the models, while the validation data are reserved for the final evaluation and comparison of their predictive performance.

Feature Scaling: Linear Regression is fitted using the encoded predictors without scaling. For KNN regression, the predictors are standardized using a pipeline because KNN calculates distances between observations and is sensitive to differences in variable scales. The scaling parameters are calculated using only the training data to avoid data leakage.

4. Linear regression: baseline and feature selection¶

Multiple linear regression models log sale price as an additive combination of the encoded predictors. First fit a full-feature baseline. Then use forward sequential feature selection with five-fold cross-validation on the training data: at each stage, candidate features are evaluated using cross-validated mean squared error, and the selector builds a smaller set. Refit linear regression on the selected training features.

Why this approach? Comparing the full and selected models shows whether reducing predictors helps on the held-out sample. Cross-validation separates feature selection from final holdout evaluation. This is a revision of the original coursework, which also explored correlation-guided selection and forward/backward procedures using AIC/BIC; the methods and resulting scores should not be presented as identical.

5. K-Nearest Neighbors (KNN) Regression¶

K-Nearest Neighbors (KNN) regression predicts the sale price of a property based on the target values of its nearest neighbors in the training dataset.

Unlike Linear Regression, KNN does not assume a linear relationship between property characteristics and sale prices. Instead, it identifies similar properties based on their predictor values and uses their average log-transformed sale price to generate a prediction.

Because KNN relies on distance calculations, all predictors are standardized using StandardScaler() within a machine learning pipeline. This ensures that scaling parameters are calculated using only the training data during cross-validation, reducing the risk of data leakage.

5.1 Hyperparameter Tuning¶

The number of neighbors (k) is an important hyperparameter that influences KNN predictions.

To select an appropriate value, GridSearchCV evaluates 15 candidate values of k, ranging from 1 to 15, using five-fold cross-validation on the training dataset.

Each candidate model is evaluated using Mean Squared Error (MSE), and the value of k with the lowest average cross-validated MSE is selected.

The selected model is then refitted using the complete training dataset and evaluated on the separate validation dataset.

Result: Cross-validation selected k = 3, indicating that using the three nearest neighbors produced the lowest average MSE among the candidate values tested.

6. Model evaluation and comparison¶

The predictive performance of the three regression models is evaluated using the same validation dataset, which was not used during model training, feature selection, or hyperparameter tuning.

The models evaluated are:

  • Linear Regression using all available predictors.
  • Linear Regression using predictors selected through forward feature selection.
  • KNN regression using standardized predictors and the selected number of neighbors (k = 3).

Evaluation Metrics¶

Model performance is assessed using three evaluation metrics:

  • R² (Coefficient of Determination): Measures how well the model explains variation in log-transformed sale prices compared with predicting the average log sale price. Higher values indicate better predictive performance.
  • RMSE (Root Mean Squared Error): Measures prediction errors, giving greater weight to larger errors. Lower values indicate better predictive performance.
  • MAE (Mean Absolute Error): Measures the average absolute difference between actual and predicted values. Lower values indicate better predictive performance.

Interpretation of Results¶

Because all three models predict the natural logarithm of sale price, RMSE and MAE are reported in log-price units rather than dollars.

For example, an RMSE of 0.237 represents a prediction error measured on the logarithmic scale. It does not mean an error of $0.237 or 23.7%.

The models are compared using the same validation dataset and evaluation metrics to assess their relative predictive performance.

The following visualizations compare actual and predicted housing prices. Log-transformed predictions are converted back to the original dollar scale using the exponential function (np.exp()) to make the results easier to interpret. The plots use logarithmic axes to display properties across a wide range of sale prices.

Relationship to the original course submission¶

The Spring 2024 report recorded R² = 0.81, RMSE = 0.25, MAE = 0.18 for linear regression and R² = 0.86, RMSE = 0.21, MAE = 0.15 for KNN (k = 4). Those are original coursework results, not outputs of this revised notebook. The original report discussed AIC/BIC feature selection; this revised analysis uses training-only cross-validation for selection and a scaled KNN pipeline. The two sets of metrics are not directly interchangeable.

The course report highlighted living area and special-feature value as relevant variables. Correlation and predictive performance alone do not establish causal effects. The evaluation uses a random split from one historical dataset, not an external or prospective test; location and time may influence how well the models generalize. Future work could evaluate later sales or a separate geographic sample and compare additional regression algorithms.

7. Results, Interpretation, and Limitations¶

7.1 Key Findings¶

The three regression models were evaluated using the same validation dataset to compare their predictive performance.

KNN Regression

The scaled KNN model with k = 3 achieved the highest R² (0.825) and the lowest prediction errors (RMSE = 0.237 and MAE = 0.165) among the three models evaluated. These results indicate that KNN captured the relationships between property characteristics and log-transformed sale prices more effectively than the Linear Regression models on the validation dataset.

Linear Regression and Feature Selection

The Linear Regression model using all 28 predictors achieved an R² of 0.788, RMSE of 0.260, and MAE of 0.190. The feature-selected model used only 14 predictors and achieved nearly identical results, with an R² of 0.787, RMSE of 0.261, and MAE of 0.191.

These findings indicate that reducing the number of predictors by 50% did not substantially affect predictive performance on the validation dataset.

The feature-selected model offers a simpler alternative that may be easier to interpret and maintain while requiring fewer input variables. Reducing the number of predictors may also help limit unnecessary model complexity and reduce the risk of overfitting, although these potential benefits were not directly evaluated in this analysis.

Overall Finding

KNN achieved better predictive performance than both Linear Regression models on the validation dataset. However, the results are specific to the dataset and modeling approach used in this project and do not guarantee similar performance on future housing sales or properties in other geographic areas.

7.2 Limitations and Future Work¶

The models were evaluated using a randomly selected validation dataset from the original Miami housing data. Their predictive performance on future housing sales or properties in other geographic areas has not been tested.

Additionally, the analysis identifies relationships between property characteristics and sale prices but does not establish cause-and-effect relationships.

Future work could evaluate the models using more recent housing sales or data from other geographic areas to assess how well they generalize to new data. Additional regression methods, such as Random Forest and Gradient Boosting, could also be explored to determine whether they improve predictive performance.
